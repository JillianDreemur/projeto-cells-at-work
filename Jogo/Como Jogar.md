# Como Jogar

| | |
|---|---|
| **Você** | [[Glóbulo Branco]]: ataque e atire nos vírus. |
| **Objetivo** | Atravessar as 4 telas da veia ([[Cenários]]) e garantir que o oxigênio chegue ao destino. |
| **Game over** | Se o coração (sua vida) zerar **ou** se qualquer [[Vírus]] alcançar a [[Glóbulo Vermelho]]. |

## Vida
A vida do jogador é representada pelo coração no HUD:

![[coracao.png|64]]

Cada golpe sofrido tira uma batida. Quando zera, é game over.
