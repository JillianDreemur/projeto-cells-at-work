# Especificações Técnicas

| Item              | Valor                                              |
| ----------------- | -------------------------------------------------- |
| Resolução da tela | **160 × 144 px** (proporção de Game Boy)           |
| Cenários          | 4 telas de **1504 × 144 px** (rolagem horizontal)  |
| Personagens       | quadros de **24 × 32 px**                          |
| Inimigo           | **24 × 24 px**                                     |
| Ícones de HUD     | **16 × 16 px**                                     |
| Arte              | pixel art no [Aseprite](https://www.aseprite.org/) |
| Áudio             | uge                                                |

Os sprites só existem virados para a direita. Para a esquerda, espelhe na engine (flip horizontal).
